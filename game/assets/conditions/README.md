# Condition markers

Copied from the WoundBound repo's Owlbear extension (src/WoundBound.Web/OwlbearFrontend/public/conditions), where they are drawn on token corners. Same files, same meaning.

The game adds a few of its own in the same style, for what the extension doesn't mark: blessed (Buff), cursed (Bane), helped, harried, shield (raised over it), holding (has somebody Held), running (nerve broken), light (carries one) and offfooting (must regain its footing).
